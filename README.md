# 7sRef

植物大战僵尸风格的网页小游戏：一群中二企鹅从右边往左走，你在草坪上放下伙伴挡住它们。纯前端、无构建、无第三方依赖。

## 在线游玩

**https://enana-ena.github.io/7sRef/** —— 推 `main` 分支就自动重新发布。本地用 Chrome / Edge 直接打开 `index.html` 就行，不需要服务器；存档各存各的浏览器，两边互不相通。

## 一局怎么玩

草坪是 5 行 × 10 列，怪物从最右边场外走进来、一路向左啃；只有靠左的 9 列能放伙伴（个别关卡只开放其中几行）。

- **奶是唯一的资源。** 顶栏最左是奶量，放伙伴要花它。奶会自然从草地上掉出来，产奶的伙伴也会掉，钱袋奖励一次爆出一大批；掉出来的奶要点掉才进账，放着不管会过期消失。菜单里勾"自动收集"后代为收集。
- **放伙伴。** 点卡槽或按数字键 `1`~`6` 选中卡片，半透明的卡片跟着鼠标，点空格子放下；再点一次同一张、点卡片本身、右键或 `Esc` 取消。放下的伙伴按自己的冷却重新可用，顶栏上的遮罩自下而上退掉就是冷却进度。
- **挡住它们。** 任一怪物的贴图越过场地左边界，本局立刻失败，弹出失败面板（可以重来或回主菜单）。
- **通关。** 打完本关最后一波、场上清空之后，会从敌人头顶掉落一枚奖励。点它：先收掉场上还没点的奶、爆出一批奶，然后大约五秒的白光结算演出，回主菜单。所以这个游戏只有"失败"面板，通关是靠掉奖励 + 演出来表达的。
- **最后一道防线。** 每行最左边停着一颗金牛奶。还没濒死的怪物贴到它，它就向右发射出去，一路把沿途的怪物全部清掉，飞出屏幕就消耗掉了。

## 伙伴卡片

卡片大致有这么几类，同一张卡也可能兼具几种能力：

- **射手**：这一行视线里有怪就开火，一发一发地打；有的子弹带减速，有的会上下各射一发。
- **纯墙**：不开火，只靠自己的血量挨啃。
- **产奶**：定期往草地上吐奶，是前期的经济来源。
- **定时自爆**：放不下几秒就炸，覆盖一片格子，啃不动它，炸完连怪物带自己都清掉、不留尸体。
- **三段卡**：埋在地下一段时间没人踩它才出土，出土完成后进入激活，此后任意怪物碰到它就原地引爆。
- **冰冻**：到期时对全场无差别来一次冰爆，怪物冻住期间既不走也不啃，还附赠很长的减速。

每张卡有价格与冷却档位（快 / 慢 / 极慢），越慢的卡开局还要多等一段首张冷却。

## 怪物

现役只有一种怪（中二企鹅）的三个变体：普通、戴"过去"防具、戴"未来"防具。

- **防具先替本体挡伤害**：一类防具会全额吃掉打在它身上的伤害，只有超出的部分才落到本体；没打穿之前本体看着像无敌，其实在掉的是防具的血。防具被打穿会掉落一片残骸。
- **濒死**：本体血量跌破临界值后停止啃食、原地冻住，一路流血直到倒下。
- **离场演出**：正常打死是向左倒地，被范围伤害炸死不留尸体，被"化灰"类伤害打死则整个变黑站一会儿再消失。
- 怪物会随机速度前进、随机分行出现，波次越往后每波的数量越多，每隔十波和最后一波是"大波"，屏幕上方会先弹出警告横幅。

## 关卡

- **关卡1-1**（主菜单"开始游戏"）：冒险模式的首关，也是唯一有教学提示条的一关。只开放中间一行草坪，开局奶很充裕，一共 4 波；出怪和掉奶都要等你先放下伙伴才开始计时。首次通关掉落的不是钱袋，而是一枚卡片奖励——领了它才解锁新的伙伴卡。
- **测试场景1**：传送带关卡。顶栏不画卡槽而画一条带子，卡片从左边陆续送进来，点带上的卡拿在手里再放到场上，**不花奶、不等冷却**，草地也不自然掉奶。
- **测试场景2**：常规沙场，30 波、三种怪混着刷，开局要自己从卡池里选一套阵容。

每一关进场的流程是：先看一段战前全景（敌方阵容从右往左平移，配战前音乐和 `3 / 2 / 1 / START!` 倒计时）；可用卡片比顶栏槽数多的话，中间还会停在选卡界面让你自己挑。右下角的进度条显示本关打到第几波，大波的位置摆着评级图标。

## 主菜单与存档

- 三枚按钮：**开始游戏**（进入冒险模式的下一关，全打通之后会提示"该内容还未开发"）、**测试场景1**、**测试场景2**。右上角是**导入 / 导出**（把存档读写到本地目录，只有 Chromium 系支持），右下角是**清除缓存**（二次确认后把全部进度复位）。
- 关卡进行中的进度只在离开这一关时写盘；"是否已通关""解锁了哪些卡片"记在另一份全局记录里，不随导入导出走。
- 战斗中的菜单面板有几个会话级开关：**快速模式**（时间两倍速）、**自动收集**所有关卡都能开；**关闭自然出怪**、**无冷却无花费**只在测试场景里出现。
- **断网**：按 `` ` `` 或点顶栏的断网位取出工具，再点某个伙伴直接把它摘掉（不会触发它的身亡特效）。测试场景常驻这个工具，冒险关卡目前还没有解锁途径。
